Under the Hood

Hand-Built Engine

No Unity. No Godot. No Unreal. Every system written from scratch, self-contained in a handful of header files.

// project structure Kraken2D/ ├── CMakeLists.txt └── src/ ├── Engine.h ← window, loop, input ├── Audio.h ← wave synthesis ├── MiniFont.h ← bitmap font ├── main.cpp ← 8 lines └── games/ ├── Menu.h ├── Tetris.h ├── Asteroid.h ├── BrickBreaker.h ├── Snake.h ├── SpaceInvaders.h └── Pong.h
⏱

Fixed Timestep Loop

Physics runs at exactly 60Hz regardless of render speed. No drift, no jitter.

🎵

Procedural Audio

Sine, square, and noise waves synthesized at runtime via SDL3. Zero audio files.

🖥

Resolution-Aware

Every game reads actual screen dimensions each frame — scales to any monitor.

🎬

Scene Manager

Hot-swap between games via string IDs with onEnter/onExit lifecycle hooks.

📝

5×7 Bitmap Font

Full A–Z, 0–9, symbols. Any scale, no SDL_ttf. Includes pixel-art heart lives display.

💥

Inline Physics

AABB, circle, and polygon collision inlined per-game. No shared library overhead.

🤖

Predictive AI

Pong AI calculates exact bounce trajectories but adds human-like reaction delay and aim error.

🪟

Borderless Windowed

SDL_WINDOW_BORDERLESS | MAXIMIZED — fullscreen feel, no mode switch. Alt-Tab works.

Get Started

Build & Run

MinGW + SDL3 on Windows. Under 5 minutes from clone to running.

Requirements

g++ (MinGW-w64)v13+
CMakev3.16+
SDL3v3.4+
PlatformWindows (MinGW)
SDL3 extracted to C:/SDL3-3.4.4/
with MinGW dev package inside
x86_64-w64-mingw32/
bash 
# configure
mkdir build && cd build
cmake .. -G "MinGW Makefiles"

# build
cmake --build .

# copy SDL3 DLL
cp C:/SDL3-3.4.4/x86_64-w64-mingw32/bin/SDL3.dll .

# run
./Kraken2D.exe
