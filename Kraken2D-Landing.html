Under the Hood

Hand-Built Engine

No Unity. No Godot. No Unreal. Every system written from scratch, self-contained in a handful of header files.

Kraken2D/ ├── CMakeLists.txt └── src/ ├── Engine.h ← window, loop, input ├── Audio.h ← wave synthesis ├── MiniFont.h ← bitmap font ├── main.cpp ← 8 lines └── games/ ├── Menu.h ├── Tetris.h ├── Asteroid.h ├── BrickBreaker.h ├── Snake.h ├── SpaceInvaders.h └── Pong.h
⏱
Fixed Timestep Loop
Physics runs at exactly 60Hz regardless of render speed. No physics drift, no jitter.
🎵
Procedural Audio
Sine, square, and noise waveforms synthesized at runtime via SDL3 audio streams. Zero audio files.
🖥
Resolution-Aware Layout
Every game reads actual screen dimensions each frame. Scales correctly to any monitor, any resolution.
🎬
Scene Manager
Hot-swap between games via string IDs with onEnter/onExit lifecycle hooks. Menu → game → menu in one keypress.


📝
5×7 Bitmap Font
Full A–Z, 0–9, symbols. Renders at any scale, no SDL_ttf needed. Also includes pixel-art heart rendering for lives display.
💥
Inline Physics
AABB, circle, and polygon collision math inlined per-game. No shared physics library — each game only carries what it needs.
🤖
Predictive AI
Pong AI calculates exact bounce trajectories but adds reaction delay and aim error to be humanly beatable.
🪟
Borderless Windowed
SDL_WINDOW_BORDERLESS | SDL_WINDOW_MAXIMIZED — fullscreen feel with no exclusive mode switch. Alt-Tab works instantly.

Get Started

Build & Run

MinGW + SDL3 on Windows. Should take under 5 minutes from clone to running.

Requirements
g++ (MinGW-w64) v13+
CMake v3.16+
SDL3 v3.4+
Platform Windows (MinGW)
SDL3 should be extracted to C:/SDL3-3.4.4/
with the MinGW dev package inside
x86_64-w64-mingw32/
bash 
# clone / extract project
cd Kraken2D

# configure
mkdir build && cd build
cmake .. -G "MinGW Makefiles"

# build
cmake --build .

# copy SDL3 DLL
cp C:/SDL3-3.4.4/x86_64-w64-mingw32/bin/SDL3.dll .

# run
./Kraken2D.exe
